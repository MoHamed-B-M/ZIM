# Changelog

All notable changes to ZIM are listed here, newest first. The in-app
updater reads the top section to show “What's new”.

## [Unreleased]

## [1.0.0]

- Notes, checklists, tags, pins, archive and trash (30-day auto-purge)
- Instant local full-text search with match highlighting
- Expressive UI: floating bottom bar, animated menus, dynamic color
- Three switchable launcher icons (Midnight, Paper ring, Stack)
- In-app updater with Stable and Beta channels, download and install
- Opt-in cloud sync via WebDAV / Nextcloud or custom REST (last-write-wins)
- Password-encrypted local backups plus plain JSON export and import
- App lock with passcode, pattern or fingerprint, and screen protection
- Per-app language picker and monospace font option
- Theme mode, dynamic color, custom seed colors, font size and corner radius
- Full markdown rendering with images, links, quotes and tables
- Home-screen widgets: latest note and quick-add button
- Drag and drop images and files into notes from floating windows
- Signed CI builds with beta `beta-latest` prerelease and versioned stables
- Based on EasyNotes by Kin69, GPL-3.0 licensed
